# よみとき：招待制無料体験ベータ

## 現状と目的

2026-11-02に新規Gemini APIキーで404を経験した利用者が、キーを取得せずに使えるようにするための実装。既存の「自分のGemini APIキーで測る」経路はそのまま残す。

**このブランチだけでは利用者はまだ使えない。** Cloudflare Workerのデプロイ、Secret登録、実際の有料キーによる動作確認、エンドポイント接続が必要。これらの作業が済むまで招待制UIは非表示。

## 安全な導入手順

1. Cloudflare Workersアカウントを準備。yomitoki/trial-worker/ で npx wrangler deploy を実行。初期状態は TRIAL_ENABLED=false（外部利用は停止）。
2. Cloudflare WorkerのSecretに GEMINI_API_KEY を登録（現在成功した**有料枠のキー**）。npx wrangler secret put GEMINI_API_KEY。**値をGitHub、PR、チャットに貼らない**。
3. 別の十分長い招待コード（暗号学的乱数で生成した48桁以上の値）をCloudflare Secret INVITE_CODE に登録。npx wrangler secret put INVITE_CODE。コードは今回の利用者一人だけに安全な手段で知らせる。APIキーとは別物。
4. wrangler.jsonc の GEMINI_MODEL を、運営者の**有料キーで実際に動作確認したモデルID**に設定する。2.5/3.8等を名前だけで推測して決めない。今の値は仮設定。
5. wrangler.jsonc の TRIAL_ENABLED を "true" にして再デプロイ。本番URLはCloudflare WorkerのURL。
6. GitHub Pages側 yomitoki/trial-config.js の YOMITOKI_TRIAL_ENDPOINT に、末尾スラッシュなしで実際のWorker URLを設定し、公開する。**APIキーや招待コードはここへ書かない**。
7. 招待者の端末で「招待制の無料体験」を選択し、実測で検品が完了することを確認する。

ALLOWED_ORIGIN は https://takibi-tools.github.io だけを許可する。ローカル試験時は別設定で明示的に変更し、本番では戻す。Originは認証ではないため、ランダム招待コードとセッショントークン、サーバー側回数制限を併用する。

## 利用制限

- 日本時間0時で日次集計を更新。
- **成功した測定3回/日**。Gemini失敗の場合は成功回数を消費しない。
- 失敗を無限に試せないよう、測定開始は6回/日まで。
- 1測定につき最大6回のGemini呼び出し、日次30回の呼び出し制限。
- 503には最大2回の短い自動再試行。その他の失敗で勝手にモデルを切り替えない。
- 20分でセッション失効。二周検品・修正呼び出しも同じ「1回の測定」内で計上する。
- **上の制限はAPI通話回数の上限であり、正確な円建て予算上限ではない。** Google側の課金管理・アラートと合わせて実測費用を監視する。運営者が停止したいときは TRIAL_ENABLED=false にするかWorkerを停止する。

## データと注意

- よみときの質問・文章は利用者のブラウザからWorkerを経由してGemini APIへ送信。
- Workerの実装は質問・文章を保存せず、回数・セッションハッシュのみ保存。運営側のログ収集設定やGoogle側でのデータ処理は別途確認する。
- ブラウザの元の「自分のAPIキー」モードは従来どおりブラウザ内にキーを保存するため、共用端末の注意表示を維持。
- 招待コードは、共有されたら使い回され得る。まず1名限定の試験として運用し、本格公開時には別の不正利用対策を設計する。
- 異なるAIモデルでの測定は研究の比較可能性に影響する。無料体験版のモデルを別に記録する。

## テスト項目

- [ ] 無効な招待コードを拒否。
- [ ] WorkerのSecretが未設定のとき拒否。
- [ ] 招待コードで生成が成功する。
- [ ] 1日3件成功したら4件目を拒否。
- [ ] 失敗時に成功枠は減らない（ただし開始試行上限あり）。
- [ ] 同一セッションの二重完了で二重課金しない。
- [ ] 503の再試行を最大2回に制限。
- [ ] フロントエンドに運営者APIキーが露出しない。
- [ ] 既存のAPIキーモードとサンプル表示が引き続き動く。
- [ ] 招待された利用者本人の環境で実際に完走。

## ロールバック

GitHub Pagesの yomitoki/trial-config.js のURLを空欄にすると、招待制UIは非表示になり、既存のAPIキーモードだけになる。Worker側も TRIAL_ENABLED=false に戻す。
